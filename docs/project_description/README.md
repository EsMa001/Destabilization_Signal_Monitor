# Project Description Package

Dieses Verzeichnis enthaelt eine konsolidierte Projektbeschreibung des Country Destabilization Prototype.

## Dokumente

1. `scientific_paper.md`  
   2-3-seitiges wissenschaftliches Paper mit Abstract, Methode, Architektur, Verifikationsstand und Diskussion.

2. `scientific_paper_formal.md`  
   Formalere wissenschaftliche Fassung mit expliziter Related-Work-/Literatur-Struktur, Limitations- und References-Abschnitt.

3. `executive_summary_de.md`  
   Deutsche Executive Summary fuer Management-, Review- oder Stakeholder-Kommunikation.

4. `detailed_documentation.md`  
   Sehr detaillierte Projektdokumentation mit Ziel, Softwareaufbau, mathematischen Ansaetzen, aktuellem Stand, offenen Punkten und Weiterentwicklung.

5. `exports/README.md`  
   Beschreibung der exportfaehigen HTML-, DOCX- und PDF-Fassungen.
