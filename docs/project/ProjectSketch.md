# Formale Projektskizze

## Ziel
Entwicklung eines erklärbaren, testbaren und erweiterbaren Prototyps zur Identifikation kurzfristiger Destabilisierungssignale.

## Gegenstand
Betrachtet werden Iran, Israel und Deutschland entlang der Cluster Spannung, Eskalation und Verwundbarkeit.

## Abgrenzung
Kein operatives Vollsystem, kein vollständiger Ersatz kuratierter Eventdatenbanken, keine globale Multi-Country-Plattform in V1.

## Methodik
Rohdaten -> Features -> Subscores -> Cluster-Scores -> Baseline-Einordnung -> Stufen / Trend / Confidence -> Handout / Outputs

## Outputs
- Report / Handout
- Plots
- CSV / JSON Exporte
- Run-Metadaten
- Run-Status
- Referenz-Run

## Risiken
- Medienbias
- heterogene Länderprofile
- begrenzte Ereignisgrundlage
- Scheingenauigkeit
- Erweiterungsdruck

## Ausbaupfad
- weitere Quellen
- adaptive Schwellen
- komplexere Fusion
- weitere Länder
- tiefere regionale Auflösung
